# Personal Portfolio Website

A simple and responsive personal portfolio website built using HTML and CSS. The website consists of two main pages: a Home page that introduces me and my work, and a Contact page that provides ways to get in touch.

## Features

* Clean and responsive design
* Home page with personal introduction
* Contact page for communication details
* Easy navigation between pages
* Built using pure HTML and CSS

## Technologies Used

* HTML5
* CSS3

## Project Structure

* **Home Page:** Displays basic information, introduction, and portfolio content.
* **Contact Page:** Provides contact details and communication options.
